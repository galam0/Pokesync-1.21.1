# 🌟 PokeSync - 픽셀몬 동기화 플러그인 🌟

PokeSync는 포켓몬(Pixelmon) 플레이어 데이터를 손쉽게 동기화하도록 설계된 Spigot 플러그인입니다. [HuskSync](https://github.com/WiIIiam278/HuskSync?utm_source=gemini)에서 영감을 받아 제작되었으며, 일부 코드를 활용하여 매끄럽고 효과적인 데이터 동기화를 보장합니다.

새로운 **2.0** 버전은 [Husksync v3.6.8](https://github.com/WiIIiam278/HuskSync)을 필수 요구하며, 또한 libs 파일 속에 픽셀몬 9.3.16 모드를 넣어야 플러그인 컴파일이 가능합니다  **1.21.1** 버전만 지원합니다.

## 🚀 주요 기능

* 🎯 **유연한 설정**: 설정 파일(config)을 통해 동기화할 데이터를 쉽게 선택할 수 있습니다.
* 💎 **광범위한 데이터 지원**: 지닌 포켓몬(Party), PC, 머니(Money), 키우미집(Daycare), 퀘스트(Quest), 메가링/아이템(MegaItem), 부적(Charm), 도감(Dex), 루어(Lure), 코스메틱(Cosmetic) 등 다양한 항목 지원!
* 🌐 **다양한 버전 지원**: 다양한 버전의 Pixelmon과 호환됩니다.

## 🌐 호환성

* 모드 버킷 1.21.1 지원
* **[Pixelmon Reforged](https://reforged.gg/?utm_source=gemini)** 9.3.16 버전만 지원

## 📝 설정 (Configuration)

플러그인의 설정 파일 내에서 동기화할 항목을 직접 선택할 수 있습니다.
